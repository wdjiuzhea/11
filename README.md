# Wired Remote Blocker 2.0（测试版）

## 重要修正

旧版只要检测到有线耳机就按键码拦截，可能连机身音量键一起挡掉。v2 **默认不拦截任何按键，直到识别耳机输入来源**，并允许把机身按键来源设为保护名单。

## 安装

解压项目内容到 GitHub 仓库根目录，Actions 编译成功后下载 Artifact 中的 `app-debug.apk`。签名与旧版不一定相同；如果升级安装提示签名不一致，请先备份需求并卸载旧版。

## 使用流程

1. 在手机无障碍设置启用耳机线控屏蔽服务。
2. 插上耳机，按一下**手机机身音量键**，打开本 App，点「把最近一次按键记为手机机身按键」。
3. 触发一次**耳机线控**（或等待其误触），回到 App 点「把最近一次按键记为耳机线控」。
4. 仅当设备来源确实不同，打开「启用过滤」并按需打开「同时屏蔽音量加减」。
5. 在音乐界面和桌面分别测试耳机线控与手机音量键。

如果两者 `id` 相同或者没有收到耳机事件，普通无障碍应用无法保证只处理耳机来源，建议硬件隔离线控/更换转接头。

## 限制和安全

- 无法修复杂音、接触不良、DAC 故障。
- Android 设备 ID 可能因重插变化，程序优先使用输入设备 descriptor 识别。
- 某些系统会把耳机按键映射成通用或虚拟输入设备，不能与机身按键区分。
- 无障碍服务可能无法接收到音频固件层/系统层已经处理的按键。
- 安卓只允许一个无障碍按键过滤服务真正接收全局按键。
- 这是源代码，当前工作环境未安装 Android SDK，因此本地未执行 Android 编译或真机测试。

## 构建

仓库根目录包含 `.github/workflows/build-apk.yml`，在 GitHub Actions 运行 `:app:assembleDebug`。
